CHANGES MADE:
================================================================================

1. MAKEFILE UPDATES
   - buildroot-setup: Changed from git clone to tar extraction
     * Extracts from: sources/buildroot-2023.11.tar.xz
     * Speed: Instant (no network)
     * Validates archive exists before extraction

   - crosstool-setup: Changed from git clone to unzip extraction
     * Extracts from: sources/crosstool-ng-crosstool-ng-1.28.0.zip
     * Speed: Instant (no network)
     * Validates archive exists before extraction

   - check-deps: Updated to check for tar/unzip instead of git
     * tar: Required for buildroot extraction
     * unzip: Required for crosstool-ng extraction
     * git: No longer required!

   - NEW check-sources target:
     * Verifies both archive files are present
     * Shows file sizes and locations
     * Required for offline builds

   - distclean: Updated to preserve sources/ directory
     * Archives are NEVER deleted
     * Only extracted directories are removed
     * Re-extraction is always possible

   - help: Updated to show new offline capabilities
     * Added check-sources command
     * Added Source Archives section
     * Explains local archive usage

2. DOCUMENTATION
   - NEW: OFFLINE_BUILD.md (complete offline guide)
   - README.md: Added offline build info
   - README.md: Removed git from requirements
   - README.md: Added check-sources documentation
