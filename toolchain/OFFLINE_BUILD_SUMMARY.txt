HOW IT WORKS NOW
═══════════════════════════════════════════════════════════════════════════════

BEFORE (Git Clone - Requires Network):
  $ make buildroot-setup
  → Clones from git.buildroot.net (slow, requires internet)
  → Depends on network availability
  → Can fail with timeouts/firewall issues

AFTER (Archive Extraction - Offline):
  $ make buildroot-setup
  → Extracts from local archive in seconds
  → NO network required
  → FAST and RELIABLE
